# Dream Better In Spanish

Personal web app for learning Spanish through podcasts. Plays a podcast episode with a synchronized two-pane view: Spanish transcript on the left, English translation on the right, with the current segment highlighted as the audio plays.

The processing pipeline is Python (faster-whisper for transcription + Anthropic Claude for translation). The frontend is plain static HTML/CSS/JS served by `python -m http.server`.

## Prerequisites

- macOS or Linux (CPU-only Whisper works fine on Apple Silicon)
- Python 3.11+
- [`uv`](https://docs.astral.sh/uv/) for dependency management
- An Anthropic API key

## One-time setup

```sh
# Install dependencies into a project venv
uv sync

# Create your .env
cp .env.example .env
# Then edit .env and set ANTHROPIC_API_KEY=...
```

The first pipeline run will additionally download the `faster-whisper-medium` model (~1.4 GB) into `~/.cache/huggingface/`. Subsequent runs use the cache.

## Pipeline: turn podcast episodes into transcripts

The pipeline reads the Dreaming Spanish RSS feed, downloads audio for a single episode, transcribes it with Whisper (locally, on CPU), and translates each segment with Claude. Output is written to `data/episodes/<episode-id>.json` and the episode is registered in `data/index.json`.

```sh
# List the most recent episodes in the feed (* marks already-processed)
uv run python -m pipeline.main list

# Limit the listing
uv run python -m pipeline.main list --limit 10

# Process the newest unseen episode end-to-end
uv run python -m pipeline.main process-latest

# Process a specific episode by ID (use an ID shown by `list`)
uv run python -m pipeline.main process-episode ds-20260512-girlhood-sisterhood-real-or-romanticized

# Re-process an episode that's already on disk
uv run python -m pipeline.main process-latest --force
```

**Time and cost per episode** (≈30 min of audio):

- ~30–40 min of CPU time for Whisper transcription (one-time per episode)
- ~$0.05–0.10 in Anthropic API charges for translation
- The MP3 is downloaded to a temp file and deleted after processing — the frontend streams audio directly from the podcast CDN.

## Frontend: play episodes in the browser

Serve the project root so both `/web/` and `/data/` are reachable on the same origin:

```sh
uv run python -m http.server 8000
```

Then open:

- <http://localhost:8000/web/index.html> — episode picker (lists everything in `data/index.json`)
- <http://localhost:8000/web/player.html?ep=<episode-id>> — direct link to a specific episode

The player offers:

- Synced highlighting of the current segment as audio plays
- Click any segment to jump to that point
- Speed control: 0.5× / 0.75× / 1× / 1.25×
- Replay the current segment
- Hide-English toggle (collapses to Spanish-only)

To stop the server: `Ctrl+C` in the terminal, or `pkill -f 'http.server 8000'`.

## Project layout

```
pipeline/         Python: RSS → audio → Whisper → Claude → JSON
  rss.py            Buzzsprout RSS parser; stable IDs (ds-YYYYMMDD-slug)
  transcribe.py     faster-whisper wrapper (medium model, Spanish)
  translate.py      Anthropic SDK, batched segment translation w/ schema validation
  process.py        orchestrator
  main.py           argparse CLI

web/              Static frontend (no framework)
  index.html        episode picker
  player.html       two-pane bilingual player
  index.js
  app.js
  styles.css

data/             Generated by the pipeline (and read by the frontend)
  index.json        episode list
  episodes/         <episode-id>.json per episode
```

## Notes

- `.env` is gitignored. Don't commit your API key.
- The audio CDN (Buzzsprout) rejects requests without a browser-like `User-Agent`; the pipeline's downloader sets one. Browsers send their own, so `<audio>` playback works directly from the CDN.
- See `CLAUDE.md` for guidance written for an AI coding assistant working in this repo.
